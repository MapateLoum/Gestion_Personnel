## 🎯 Objectif du projet

Cette application permet :

- La saisie, modification et suppression des congés du personnel.
- Le suivi des périodes de congés par matricule ou par intervalle de dates.
- L’impression de documents **Word** ou **PDF** : bulletin de congé, attestation de congé, etc.
- La génération dynamique de formulaires (React + Next.js).
- L’intégration d’une base de données MySQL pour persister les données du personnel.

---

## ⚙️ Technologies utilisées

- [Next.js](https://nextjs.org/) – pour l’interface utilisateur
- [React](https://react.dev/) – pour les composants dynamiques
- [MySQL](https://www.mysql.com/) – pour stocker les agents et congés
- [Node.js](https://nodejs.org/) – pour l’API backend
- [`docx`](https://www.npmjs.com/package/docx) – pour générer des fichiers Word
- [`pdf-lib`](https://pdf-lib.js.org/) – pour les exports PDF
- CSS Modules – pour styliser les composants
